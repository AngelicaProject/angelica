# When something goes wrong

Find what you see below.

## Nothing happens when I press Insert

- If you chose another key in Angelica's settings, press that key.
- Type `/angelica` in the chat, or select **Angelica** in the game's **System** menu.
- If no note appeared at the top right when the game started, Angelica did not start. [Run the installer](install.md) again.

## A plugin stopped by itself

When a plugin fails, Angelica turns it off and the game keeps running. The plugin is listed under **Needs attention** with the reason.

- Select **Try again** to start it again, or leave its switch off.
- To tell its author, select the plugin, then **Copy report for the author**, and paste the report in your message to them.

## A plugin does not work after a game patch

See [Patch day](patch-day.md).

## A plugin waits under Needs attention

It is new, or its new version asks for something it did not have before. Select **Allow…** next to it, and decide.

## The game closed unexpectedly

1. Start the game again.
1. If it happens again, open the folder `%LOCALAPPDATA%\Angelica\logs`: paste the address into the address bar of File Explorer.
1. Send the newest files from that folder with your report, as described below.

## Report a problem

For a problem with one plugin, write to its author and include the plugin's report from **Copy report for the author**.

For a problem with Angelica itself, [open an issue on GitHub](https://github.com/AngelicaProject/angelica/issues/new) and say what you did, what you expected, and what happened instead.
