# Remove Angelica

Angelica is removed like any other Windows program.

1. Close the game.
1. Open **Settings > Apps > Installed apps** in Windows.
1. Find **Angelica**, select **⋯**, then **Uninstall**.
1. Under **Plugins and their data**, choose:

   - **Keep** them and their settings, if you might install Angelica again. They come back as they were.
   - **Delete** them, to remove everything.

1. Select **Remove**.

   If the game is in a folder like `Program Files`, Windows asks for administrator rights.

To turn off or remove a single plugin instead, see [Turn on a plugin](turn-on-a-plugin.md#turn-off-or-remove-a-plugin).
