# Patch day

After a game patch, start the game as usual. Angelica catches up with the patch by itself, and you do not reinstall anything.

## What you might notice

Until Angelica catches up, some plugins might not do everything they usually do. Everything else keeps working.

The home page of this site shows where things stand: **Up to date with the game** when Angelica has caught up, or the date of the patch while it has not.

## If a plugin still does not work

1. When the home page says **Up to date with the game**, restart the game.
1. If the plugin still does not work, select it in the Angelica window, then **Copy report**, and send the report to its author.
