# Patch day

After a game patch, start the game as usual. Angelica catches up with the patch by itself, and you do not reinstall anything.

## What you might notice

Until Angelica catches up, some plugins might not do everything they usually do. Everything else keeps working.

Angelica catches up when a new map of the game comes out for the patch. The home page of this site shows the latest map under **Map of the game**, and under **For the game update** the game update it is for.

## If a plugin still does not work

1. When the home page shows a map for the patch, restart the game.
1. If the plugin still does not work, select **⋯** next to it in the Angelica window, then **Copy report for the author**, and send the report to its author.
